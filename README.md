# GymPlus Desk releases

Installers and the auto-update feed for GymPlus Desk, the front desk app for Milestone Fitness, built by RG Devs.

Download the latest `GymPlus-Desk-Setup-<version>.exe` from [Releases](../../releases/latest).

The installer is not code-signed yet. If Windows SmartScreen shows "Windows protected your PC", choose **More info**, then **Run anyway**.

Installed copies update themselves automatically from this page.
